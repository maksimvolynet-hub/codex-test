# ФЕРРУМ · Производство

Мобильная производственная система компании ФЕРРУМ.

Роли: рабочий и начальник цеха. Рабочий работает прежде всего с телефона; НЦ — с телефона и компьютера.

Стек: React + Vite + Supabase + Vercel.

В проекте заложены задания по номеру заказа и позиции, таймеры, фото, простои, ежедневные отчёты, коэффициенты ТБ и выработки, штрафы/корректировки, расчёт зарплаты и экспорт трудозатрат.

## Запуск

1. Создать проект Supabase.
2. Выполнить SQL из `supabase/migrations` по порядку.
3. Добавить `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в переменные окружения Vercel.
4. Развернуть проект на Vercel.
